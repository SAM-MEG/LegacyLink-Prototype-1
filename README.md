# LegacyLink — Fintech Investment Prototype

LegacyLink is a fintech web prototype designed around long-term financial planning and digital legacy building.

The concept explores how parents can plan financially for important milestones in a child's future, such as education, housing or other major life goals.

The project combines a fintech-inspired interface with user-focused product thinking and interactive frontend development.

## Project Concept

LegacyLink was developed as a proof-of-concept exploring an alternative way of thinking about long-term financial planning.

The idea is to give users a clear digital space to:

- Plan towards future financial milestones
- Visualise long-term goals
- Explore a child-focused financial journey
- Interact with a simple financial dashboard
- Understand financial planning through an accessible interface
